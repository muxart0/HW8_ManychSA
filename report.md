# Лабораторная работа: анализ HTTP-трафика и тестирование XSS с использованием Scapy

## 1. Цель работы

Изучение возможностей библиотеки Scapy для перехвата и анализа сетевого трафика, а также исследование XSS-уязвимостей учебного веб-приложения Google Gruyere.

## 2. Используемые инструменты

- Windows 11;
- WSL Ubuntu;
- Python 2.7 для запуска Google Gruyere;
- Python 3 и Scapy для перехвата трафика;
- Google Chrome;
- Wireshark для дополнительного анализа PCAP.

## 3. Перехват HTTP-трафика

Для перехвата трафика использовалась библиотека Scapy. Захват выполнялся на интерфейсе lo с фильтром tcp port 8008.

В ходе взаимодействия с Google Gruyere были зафиксированы HTTP-запросы GET, содержащие адреса страниц и параметры пользовательских действий.

В качестве примеров обнаружены запросы к страницам snippets.gtl, newsnippet.gtl, newsnippet2 и saveprofile.

Результат обычного перехвата сохранён в файле normal.pcap.

## 4. Исследование XSS

В ходе исследования была выбрана точка внедрения пользовательских данных — поле создания сниппета.

Для проверки Stored XSS использовалась следующая полезная нагрузка:

    all <span style=display:none>"
    + (alert(1),"")
    + "</span>your base

После сохранения сниппета и обновления AJAX-ленты была проверена возможность выполнения внедрённого JavaScript.

Результат проверки: появилось окно alert(1).

## 5. Анализ трафика при XSS

При создании сниппета пользовательская нагрузка передавалась серверу через GET-параметр snippet запроса newsnippet2.

После сохранения сниппета браузер обращался к feed.gtl для получения данных AJAX-ленты.

В ответе сервера исследовалось содержимое JavaScript-функции _feed, в которую включаются пользовательские сниппеты.

При успешной эксплуатации внедрённое выражение alert(1) присутствует в JavaScript-ответе и интерпретируется браузером как исполняемый код.

Перехваченный трафик сохранён в файле xss.pcap.

## 6. Сравнение обычного трафика и трафика при XSS

В обычном трафике наблюдались стандартные запросы на получение страниц, создание и удаление сниппетов.

При XSS-тестировании дополнительно передавалась специальная строка через параметр snippet. После этого выполнялся запрос AJAX-обновления feed.gtl, ответ которого использовался для проверки внедрённого JavaScript.

## 7. Вывод

В ходе лабораторной работы была настроена библиотека Scapy для перехвата HTTP-трафика. Были изучены структура HTTP-запросов и ответов, параметры URL и содержимое передаваемых данных. Проведено тестирование учебного приложения Google Gruyere на наличие Stored XSS через механизм AJAX. Полученные сетевые данные сохранены в формате PCAP и проанализированы с использованием разработанного скрипта.
